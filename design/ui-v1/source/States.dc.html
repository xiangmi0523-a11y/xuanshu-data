状态组件清单

每种状态都由“图形 + 文字 + 颜色”三者共同区分，不只靠颜色；在主界面、详情、搜索、历史、导出、引用中样式一致。

正式 正式 FORMAL 实线胶囊 + 勾。规则已经批准，正常展示。
研究 · 非正式 研究 / 非正式 NON_FORMAL 虚线胶囊 + 烧瓶。每个出口都带，旁边写原因；导出文件头同样标注。
阻断 阻断 BLOCKED 实心朱色 + 禁止符。不出任何柱，只列缺什么、怎样补齐；草稿用灰色虚线框，不像命盘。
有降级 · 2 项 降级 方角赭色 + 下箭头，写明条数并列出全部原因；空缺的柱用斜纹虚框“留空”。
待确认候选 歧义候选 按柱显示 A / B：建议候选为实线框，另一候选为虚线框。确认前不作结论、不能保存。
交节边界 边界告警 空心描边 + 三角。当月节气中的“节”前后 ±2 小时；立春前后 ±24 小时。子时边界提示用同一样式，附原文说明。
远期外推 远期外推 小号点线提示，只作提示，不影响结果。2027 年及以后的节气结果显示。
治理警告 治理警告 整条记录加朱框，四要素齐全：变体已撤销批准、撤销时间、撤销依据、重新计算建议。复制、导出、改名都去不掉。
出口一致性：状态跟着结果走 非正式标记与治理警告必须出现在下列每一个出口，样式相同。非正式标签旁写原因，原因取自该结果自己的状态记录，不统一套用。
