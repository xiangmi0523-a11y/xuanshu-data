1. 界面已冻结（【用户裁决 UI-1】）。六爻“装卦”（八宫、纳甲、世应、六亲、六神）和八字的人元司令，界面上目前都是“暂不显示 / 版本待核实”，**等你的核查结果才能开放**。
2. 契约对这类查表规则的准入要求（C-B 类）：**B 级及以上；两个独立来源一致，且定位可复核**。单一来源只能标非正式；无来源则阻断。
3. **同一转录链上的两个本子不算两个独立来源**；只读到摘要、没读原文，最多算单一来源。

## 三、填表与交回规则

1. **每张表开头先写来源块**（一张表一份即可，个别行出处不同的在该行备注里写）：

   ```
   来源1：书名｜版本或刊本｜卷 / 篇名｜页码或影像位置｜链接（如有）｜证据等级 E?｜可靠度 A/B/C
   来源2：（同上，必须与来源1 不在同一转录链）
   两源是否一致：一致 / 有出入（出入写在相应行的备注）
   ```

2. 格子按原书填。原书没有、或两个来源不一致的格子，填 `?` 并在备注写明各自的说法。**不要用推理或“通行说法”补格子**——这次要的是出处，不是推算。
3. 有版本分歧的（例如藏干某支的中气、余气次序；十二长生阴干顺逆、戊己寄宫），在备注里列出各说及出处，不要替用户选。
4. P-B-01 有一条已定：巽宫末以胡一桂所载为准。请给出胡一桂原文的定位。
5. 交回：报告（PDF 或文档均可）＋ 本文件的表格。表格请保持 CSV 代码块形式、表头和行号不变，方便程序逐格比对。
