# 玄枢（XUANSHU）UI 设计说明 —— 给 GPT 的设计输入

> 版本：2026-11-20　依据：《玄枢数据契约 v1.0》（含用户裁决 B4-1～B4-25）
> 用途：请 GPT 据此出界面风格方案与关键页面设计稿。
> 规矩：**视觉风格、布局、配色、字体、动效由你自由发挥**；但下文“硬性要求”是契约规定，**不能删、不能改写、不能弱化**。如果某条要求和你的设计想法冲突，请在设计稿旁边写明冲突点，交给用户裁决，不要自行取舍。你的方案在用户说“可以”之前都只是建议。

---

## 一、产品是什么

- 中文术数研究工具，iPhone App，**完全离线**。模块：八字排盘、六爻装卦、历法（节气、干支）、风水（第一版只有八宅查表）、古籍检索（本地全文搜索）、个人研究分支。
- 第一阶段**没有任何联网 AI**。本地搜索、规则计算**不得在界面上称为“AI”**。
- 规则的“正式批准”不在手机上做：App 里**不能有“批准 / 撤销批准 / 设为正式”之类的按钮**，App 只读取批准状态。
- 用户群：认真做研究的人。界面要让人一眼看清“这个结果有多可靠、为什么”，而不是把不确定的东西包装成确定答案。

## 二、请交付

1. **2～3 套整体风格方向**（色板、字体、质感、图标风格），每套配一张代表性页面。
2. 用户选定风格后，出下列**关键页面**的设计稿（iPhone 竖屏）：
   1. 首页 / 模块入口
   2. 八字出生资料输入（含时间精度、性别、地点与时区确认）
   3. 八字结果页：正常完整结果
   4. 八字结果页：**有歧义、需用户确认候选**（见 4.3）
   5. 八字结果页：**降级结果**（性别未知、时辰未知三柱模式，见 4.2）
   6. 八字结果页：**被阻断、不能出结果**（见 4.1）
   7. 参数设置页（含锁定参数公示、首次强制选择）
   8. 六爻起卦与装卦结果页
   9. 古籍检索结果页与原文页
   10. 历史记录 / 快照列表（含治理警告样式）
   11. 删除个人资料确认页
3. 一页**状态组件清单**：正式、研究（非正式）、阻断、降级、歧义候选、边界告警、远期外推、治理警告——每种状态的标记样式，保证在所有页面上一致。

## 三、全局硬性要求

1. **三种结果状态，必须一眼可分：**
   - 正式（FORMAL）：正常展示。
   - 研究 / 非正式（NON_FORMAL）：在**每一个出口**都带明显标记——主界面、详情、搜索结果、导出文件、历史记录、引用展示、缓存出来的列表，都不能丢标记。标记旁能看到原因。
   - 阻断（BLOCKED）：**不出结果**，只说明缺什么、怎样补齐。可以保存为“未完成配置”草稿，但草稿**不能长得像已完成的命盘**。
2. 搜索与列表要有筛选：**仅正式 / 仅非正式 / 全部**。
3. 已存结果（快照）**不可修改**。用户切换参数或重算时生成**新结果**，旧结果保留；新旧结果之间要能对照，**高亮四柱、十神、格局、司令干的差异**，不得静默替换。
4. 不显示秒级时间（真太阳时、交节时刻在界面上都到分钟即可）。

## 四、八字

### 4.1 输入

- **性别必填**：男 / 女 / **未知**。“未知”是用户主动选的选项，**禁止默认男或女**。
- **时间精度必填**：精确到分钟 / **只知道时辰** / **不知道时辰**。
  - 只知道时辰：让用户选 12 时辰之一（子时为 23:00–01:00）。
  - 不知道时辰：不得要求或代填任何时间（禁止默认 00:00、12:00 等）。
- 出生地点：地名 + 经纬度；时区自动解析。以下情况**必须让用户确认时区后才能出结果**，未确认则阻断：
  - 1970 年以前出生（1949 年以前内地出生一律确认）；
  - 地点或时区有歧义；
  - 出生时刻落在夏令时切换造成的**重复或跳过的那一小时**（内地 1986–1991 年有夏令时）；
  - 内地、港、澳、台以外的地区（这些地区的历史时区数据尚未核验）。
- **南半球出生暂不支持**：不提供输入路径，给出说明即可。

### 4.2 降级结果（缺输入但仍出结果）

- 结果整体标“**有降级**”，并**列出全部降级原因**（可能同时有多条，不能只显示最后一条）。
- 性别未知：四柱、十神、神煞照常；**大运不显示**，提示“补全性别可解锁大运”。
- 时辰未知：**三柱模式**——年、月、日三柱，时柱位置留空并注明原因，**不得填任何默认值**。同时必须显示这句声明（原文，不改字）：

  > 因出生时辰未知，日柱按登记日期确定，未做真太阳时切日；若出生时刻经真太阳时换算后跨过 00:00，日柱可能变动。

### 4.3 歧义与候选（需用户确认）

- 交节（节气交接）时刻附近，或只知道时辰而该时辰跨了交节 / 跨了午夜时，某些柱会有**两个候选**。
- **按柱显示**：有歧义的柱显示“候选 A / 候选 B”，无歧义的柱照常显示单值。
  - 一般节气：只有**月柱**有候选；
  - 立春：**年柱和月柱**都有候选；
  - 只知道是子时：**日柱**有候选（前一日 / 当日），**时柱只有一个值**；
  - 以上几种可以**同时出现**，各柱独立显示，互不覆盖。
- 默认高亮一个建议候选（规则固定：交节前一侧 / 换日前一侧），但**用户确认之前，不得把它当作结论**，不能保存为正式命盘；确认后才生成结果。
- 交节告警：出生时刻距离当月“节”**±2 小时内**显示边界提示；立春放宽到 **±24 小时**。
- 2027 年及以后的节气结果加“**远期外推**”小提示（只作提示，不影响结果）。

### 4.4 子时与真太阳时

- **子时规则第一版锁定**：00:00 换日；晚子时、早子时的时干都按 00:00 之后那一日的日干起。设置页**公示这个锁定值**，用户**不能更改**，也**不弹选择框**。
- 真太阳时默认开启；用户关闭时，结果页要标注“使用钟表时间”。
- 真太阳时目前只做**经度换算**，均时差尚未锁定：界面要能表达“**经度项已算、均时差待定**”，**不得出现看起来已含均时差修正的真太阳时**。
- 出生时刻在 22:30–23:30 或 00:30–01:30 时，显示子时边界提示（原文，不改字）：

  > 子时边界提示：当前采用经度换算后的时间。均时差尚未锁定，本次未将其作为确定修正量使用，实际太阳时可能存在约 ±14 分钟偏差。出生时刻接近 23:00 或 01:00 子时分界，日柱或时柱归属可能受到影响。请确认子时分界规则；本结果已标记均时差不确定性。

### 4.5 参数与输出的限制

- 有些参数**没有默认值**，首次用到时必须让用户选（如用神义项、人元司令版本、《滴天髓》版本等）；没选的，对应内容**不显示**，并说明“需先选择某参数”。
- “用神”：用户没选义项时，界面**不得出现“用神”二字**。
- 格局：只出**候选清单**，不出唯一格局。
- 神煞：只列名称与查法，**不标吉凶分数**。
- 破格：**不出任何数值分数**。
- 人元司令：只显示所选版本的天数表文本，**不显示“当令”结果**。
- 引用《滴天髓》必须**显示版本**；没选版本时不得出现“《滴天髓》云”。
- 暂缓中的规则（如大衍筮法）**不出现在普通选项列表里**。

## 五、六爻

- 起卦方式与时刻是输入；App 内摇出的结果直接保存为输入。
- 六神只作**辅助符号**展示。
- 断卦体系没选时，**不显示断语与旺衰权重**。
- 层级要分清：六亲、世应等**不得标注为《周易》原文**。

## 六、风水

- 第一版只有**八宅查表**。
- **玄空飞星排盘、立向判定：入口不存在**——不要做“敬请期待”按钮，直接不出现。
- “金锁玉关”不得称为“古籍”，只能标为近代传本。

## 七、古籍

- 原文栏要显示**版本**与**可靠度等级**（A / B / C）；转录本最高 B 级，不得显示成 A 级原文。
- 已认定的伪引 / 误引不得以“古籍原文”名义展示。
- 本地全文检索，不称 AI。

## 八、历史记录与治理警告

- 旧结果引用的规则后来被撤销批准时，在该结果的**所有出口**附警告，四要素齐全：**变体已撤销批准、撤销时间、撤销依据、重新计算建议**。警告不能被复制、导出、重命名去掉。
- 重算得到的新结果可显示“由某条旧结果重算而来”；旧结果不变、不失效。

## 九、导出

- 导出文件的文件头必须含：**结果编号（snapshot_id）、指纹、正式 / 非正式状态、导出时间**。

## 十、删除个人资料

- 用户可**整体删除**一份出生资料及其全部结果、草稿、研究记录。
- 确认页必须写明：**导出到设备外、云盘、系统整机备份（如 iCloud）或发给他人的副本，App 无法删除。**
- 从旧备份恢复时，已删除的档案**默认不恢复**，并提示用户。

## 十一、请避免

- 把不确定的东西做得像确定答案（如把候选做成单值、把研究结果做成正式样式）。
- 任何“AI 解读”“AI 推荐”字样。
- 秒级时间、精确到秒的真太阳时。
- 自行增加契约没有的功能入口（如玄空排盘、小运）。
